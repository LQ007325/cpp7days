## 环境

- **编译器**：MinGW-w64 g++ 8.1.0（C++17）
- **编辑器**：VS Code + C/C++ 扩展
- **系统**：Windows

## 怎么编译运行

仓库里带了 `.vscode/` 配置，**用 VS Code 打开这个文件夹，按 `Ctrl+Shift+B` 一步完成编译 + 运行**。

手动编译单个文件：

```bash
g++ -std=c++17 -Wall day4/p7.cpp -o day4/p7.exe
./day4/p7.exe
```

> 「编译」和「运行」是两件事：编译把 `.cpp` 变成 `.exe`，运行才真的跑程序。
