## q1　最值与差值　⭐

```
输入:  5
       3 7 1 9 4

输出:  最大值: 9
       最小值: 1
       差值: 8
```

**考什么**：`max_element` / `min_element` 的返回值**是位置不是值**，前面要加 `*`。

**⚠️ 坑**：`v` 为空时 `max_element` 返回 `v.end()`，`*v.end()` 是**越界**。要不要防一手？

## q2　平均分与高于平均的人数　⭐

```
输入:  5
       80 90 60 70 100

输出:  平均分: 80
       高于平均分的人数: 2
```

**考什么**：`accumulate(v.begin(), v.end(), 0)` 求和。**注意第三个参数 `0` 是"初始值"，不能省。**

**⚠️ 关键**：要先算出平均分，**再遍历一遍数比它大的**。不能一边算和一边比 —— 那时候平均分还不存在。

**输出提示**：这题刚好整数平均。如果不想纠结小数，`accumulate` 的初值写 `0.0` 就能出小数。

## q3　按绝对值排序　⭐⭐

```
输入:  5
       -3 1 -7 2 -5

输出:  1 2 -3 -5 -7
```

**要求：按绝对值从小到大排。** 绝对值相同时（比如 `3` 和 `-3`）随便排。

**考什么**：**lambda 自定义规则的第一关** —— 前两道题你写的都是"比较字段本身"，这题要**先加工再比较**。

**提示**：`abs(x)` 求绝对值（`#include <cmath>`）。

**规则函数长这样**：
```cpp
sort(v.begin(), v.end(), [](int a, int b) {
    return _______;          // 问：a 该排在 b 前面吗？
});
```

## q4　第 k 大的数　⭐⭐

```
输入:  6 2
       3 1 4 1 5 9

输出:  第 2 大的数是: 5
```

（第一行是 `n k`：一共 6 个数，问第 2 大的）

**考什么**：`sort` 默认是**升序**，怎么拿到"第 k 大"？

**两种思路，都要想一遍**：
- 思路 A：升序排完，第 k 大在**哪个下标**？（注意：会有重复数字）
- 思路 B：写 lambda 排成**降序**，第 k 大就在**哪个下标**？

**⚠️ 注意重复**：`3 1 4 1 5 9` 排完是 `1 1 3 4 5 9`，"第 2 大"是 `5`。**如果按"去重后的第 2 大"理解，答案也是 5** —— 但输入换成 `1 1 1 2` 就不同了。**这题按"排序后第 k 个"算**（不去重）。

## q5　出现次数最多的数　⭐⭐

```
输入:  8
       3 1 3 2 3 1 2 3

输出:  出现最多的数: 3
       出现了 4 次
```

**考什么**：**`sort` 之后相同的数会挨在一起** —— 于是"数次数"变成"数连续相同的一段有多长"。

**思路**：
```
排序后: 1 1 2 2 3 3 3 3
        └┬┘ └┬┘ └───┬───┘
         2   2      4      ← 每段长度就是出现次数
```

**写法**：遍历时比较 `v[i]` 和 `v[i-1]`：
- **一样** → 当前这段的计数器 `+1`
- **不一样** → 说明上一段结束了，**先结算**（和"目前最多"比一比），再把计数器归 1

**⚠️ 最容易漏的**：循环结束后**最后一段还没结算**！要再比一次。

**⚠️ 出现次数相同时**（比如 `1 1 2 2`）随便输出哪个都行，但**要能说出你的程序选了哪个**。

## q6　最长的单词　⭐⭐

```
输入:  I love programming very much

输出:  最长的单词: programming
       长度: 11
```

**考什么**：`getline` 读一整行 + **按空格切单词**。

**思路**：一个字符一个字符地攒：
```
遇到普通字符  →  攒进"当前单词"
遇到空格      →  当前单词结束了，结算（比长度），然后清空
```

**⚠️ 三个坑**：
1. **连续空格**（`I  love`，两个空格）—— 遇到空格时如果"当前单词"是空的，就**别结算**，否则会算出一个长度为 0 的单词
2. **行尾没有空格**（`... much` 后面直接是回车）—— **循环结束后最后一个单词还没结算**
3. **长度相同时**（`ab cd`）保留**第一个**还是最后一个？随便，但要一致

## q7　有没有重复字符　⭐⭐

```
输入:  abcdef      →  没有重复
输入:  hello       →  有重复（l 出现了 2 次）
输入:  aabbcc      →  有重复
输入:  Aa          →  有重复还是没重复？（你自己想，然后说明理由）
```

**考什么**：**`sort` + `unique` 三连的妙用** —— 你已经会用它们去重了，但**它们还能反过来判断"有没有重复"**。

**思路**：
```cpp
string t = s;                              // 复制一份，别破坏原串
sort(t.begin(), t.end());                  // 排序
auto it = unique(t.begin(), t.end());      // 挪走重复的
// 现在 it 指向"新的有效结尾"
// 如果 it - t.begin() < s.size()  →  说明有元素被挪走了 → 有重复
```

**⚠️ 这题的关键**：`unique` 返回的那个"位置"，**这次不要 erase 掉，而是拿它做判断**。

**⚠️ 大小写**：`Aa` 算不算重复？题目没规定 —— **你自己定，然后在代码注释里写明理由**。人家觉得"算"（先 `tolower`）比较合理，但你怎么定都行，**只要说清楚**。

## q8　真正严格的回文　⭐⭐⭐

```
输入:  A man, a plan, a canal: Panama   →  是回文
输入:  hello                            →  不是回文
输入:  Was it a car or a cat I saw?     →  是回文
```

**要求（比 p4 严格）：忽略大小写，**并且忽略所有非字母字符**（空格、逗号、冒号、问号、感叹号…）。

**考什么**：在 p4 的基础上**多一个"清洗"步骤**。

**思路**：先造一个新串，只保留字母：
```cpp
string t;
for (char c : s) {
    if (isalpha(c)) {                 // isalpha 判断"是不是字母"（#include <cctype>）
        t += tolower(c);              // 顺手转小写
    }
}
// 然后对 t 做 p4 那套双下标判断
```

**⚠️ 坑**：
1. **`t += c`** 是往字符串尾部追加一个字符（讲义 5.2）
2. **`isalpha` 遇到中文会怎样？** 中文不在 `char` 范围内，结果不可靠 —— **这题只用英文字符测试**
3. **清洗完可能是空串**（输入 `"!!!"`）→ 空串算不算回文？（p4 里人家说过：算）

## q9　前 3 名　⭐⭐⭐

```
输入:  5
       Alice 88
       Bob 95
       Cindy 88
       Dave 70
       Eve 95

输出:  第 1 名: Bob 95
       第 2 名: Eve 95
       第 3 名: Alice 88
```

**考什么**：**和 p7 一模一样的模式**（`pair` + lambda 多字段排序），只是输出只取前 3 个。

**规则**：分数降序；分数相同按名字升序。

**⚠️ 坑**：
1. **总人数少于 3**（比如只有 2 个学生）→ 你不能硬输出 3 行！用 `min(3, (int)scores.size())` 或者 `if` 判断
2. `scores.size()` 是**无符号数** —— 用在 `i < scores.size()` 里没问题（不加不减就行）
